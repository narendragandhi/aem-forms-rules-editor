# Support

This project is community-supported and is provided as a reference implementation. It is not an Adobe product and does not provide an SLA or production support.

For questions and reproducible defects, open a GitHub issue with:

- A short description and expected behavior
- AEM, Forms add-on, Java, Maven, Node.js, and VS Code versions
- The smallest useful reproduction and relevant logs with secrets removed
- The validation commands you ran

Use the security process in [SECURITY.md](SECURITY.md) for vulnerabilities.
